# CarCost AI 🚗

A lightweight, responsive car ownership cost calculator designed for static hosting.

## Deploy

### GitHub Pages
1. Create a repository.
2. Upload all files.
3. Enable **Settings → Pages → Deploy from branch**.
4. Select the `main` branch and `/root`.

### CloudPages / static hosting
Upload the project contents as a static website. The entry point is `index.html`.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- No build step
- No database
- No framework dependency
